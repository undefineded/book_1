# 测试：Qwen 模型的中文文字渲染

用来验证 **Qwen-Image-2.1-Turbo 能不能直接画出中文正文**，结论是：**字形全对，标点不靠谱**。

目标文字（鸟类绘本 P? 的一段正文）：

```
会移动的“小土块”
“小土块怎么会走路？”
羽羽轻声说：“那是鹌鹑（ān chún）。
那边的鹧鸪（zhè gū），也很会躲藏。”
```

## 结论

| 项目 | 结果 |
|---|---|
| 汉字 | **100% 正确**，包括生僻字 `鹌鹑`、`鹧鸪`、`躲藏` |
| 拼音 | 全对：`ān chún`、`zhè gū`，声调符号也对 |
| 标题层级 | 能理解"标题字号更大"，02 之后都做对了 |
| **行首的前引号 `“`** | **5 张里丢了 4 张** |
| **结尾的后引号 `”`** | **5 张里丢了 4 张** |
| 括号 | 拼音外面**一律输出半角 `()`**，提示词写全角也没用 |
| 纸张/卡片 | 能画撕纸边、米白纸、投影，观感不错 |

缺引号的位置**每次都不一样**，换种子不会变好，说明是模型对"行首标点"和"中文标点配对"的固有短板，不是提示词的问题。

## 生成参数

- 模型 `qwen_image_2.1_turbo_int8_convrot.safetensors`，VAE `qwen_image_2.1_vae_bf16`，文本编码器 `qwen3vl_8b_int8_convrot`
- 8 步固定 sigma 表，cfg 1.0，采样器 euler
- 纯文生图：`TextEncodeQwenImage21` 的 `images` 传空 `{}`
- 耗时：1664² 约 130 秒，2048² 约 200 秒（RTX 4060 Laptop，锁频 2190 MHz）

## 关于字体

模型**不使用字体**——扩散模型不加载字体文件，字形是训练数据学出来的像素分布。所以它输出的永远是"某一种手写感"，不可能等于某一款字。

而原卡是**真字体**排的：`LXGW WenKai`（霞鹜文楷，SIL OFL 开源可商用），标题用 Medium、正文用 Regular。用同一字体重排（`07`）能逐笔对上前面的原卡（`06` 左图），这是模型做不到的。

**要跟书里其它页完全统一，只能用字体；要"人手写"的随机笔触，才用模型。**
