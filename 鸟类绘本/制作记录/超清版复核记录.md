# 鸟类绘本旧超清版复核记录（历史）

2026-11-13：用户要求移除鸟类超清产物，`鸟类绘本/超清版/`已整体删除。下文记录的是移除前版本的制作与检查结果，不表示当前仓库仍交付这些文件。原图、扩图版、文稿与共用CUnet工具保留；本记录、技术复核JSON和制作脚本仅供历史参考。

## 处理范围

本次按提升已有图片分辨率处理，共37张：P1—P36采用当前最新扩图版，P40采用现有封底并自然补足边缘余量。P37—P39只有文稿，未补画或计入完成数。原图、原扩图版、v1与v2文稿均保留。

主文字以现有图对应的v1稿为准。P40沿用现有封底的长句“百科不只在书里，也在你窗外的第一声鸟鸣里。”，未将原短稿偷偷改成长稿；差别同时记入超清版校对文字。未套用v2重排、改章或改文案。

## 制作方法

1. 图像编辑工具仅分离旧标题、正文和百科文字，保留人物、动作、服饰、动物、道具、水彩纹理及纸片装饰；P40原构图居中缩入并自然补边。
2. 使用waifu2x-ncnn-vulkan 20250915发布的CUnet `scale2.0x_model`，ncnn 20250916原生CPU FP32两倍推理，不额外降噪；1254×1254提升至2508×2508。
3. 使用霞鹜文楷v1.530重新矢量排字；按每页纸片大小断行、调整标题颜色与文字位置。恢复P2书脊“鸟类大百科”、P31“图书馆”与P32“早餐店”原有小字。
4. Inkscape导出3000×3000、300 PPI PNG及720×720 pt（254mm方形）嵌入字体PDF。每页保留可编辑SVG、1254px无字底图和2508px超分底图。

模型权重SHA256：`d82ed30207fd07e1c16726a9ca838ce44e6e25a105b0278c7ca681516ee0e18e`。共用CPU适配器源码见[cpu_upscale.cpp](../../CUnet/src/cpu_upscale.cpp)，模型与依赖版本的来源亦见该文件。此为AI超分与重新排字，未称作原生3000px重绘。

## 目视复核

已检查全部37页无字底图、最终排版及手部放大局部。手部按握持或遮挡关系判断，未要求所有姿势都展开五指；P10保留连指手套，P3远景手部随身体自然遮挡。核对儿童关节、手腕、持书、握笔、持录音机、扶栏杆和脚下支撑。

- P15保留三只疏朗的火烈鸟、蓝灰色湖水和局部粉色倒影；未恢复旧版密集鸟群或粉色整片湖水。
- P24保留笔记本三行：灰布谷鸟与金色双音符、紫色长线；小鸟与蓝点；棕色小鸟与珊瑚色弧线。录音机真实波形独立表达。
- P30保持椅上自然坐姿与脚踏支撑；P33站立在胸前持本；P36坐在合适的椅子上听录音，双脚有脚踏支撑。
- P4正文重新断行，避开羽羽羽冠与发光场景；百科文字统一留出纸片内边距，深色纸签使用浅色标题。
- P4正文、P15标题、P31与P32正文下增加浅色阅读底，避免书架、枝条、屋檐和电线干扰，阅读底避开鸟的身体与羽翼；P36长标题分两行，文字保留在窗框左侧。P40空白纸签上移，使亲子提示位于纸签内并保持边距。
- 所有页面的标题、正文与百科均独立排字；除章名外，不将文件页码印入画面。
