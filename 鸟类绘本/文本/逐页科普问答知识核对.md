# 逐页科普问答：知识核对说明

本说明供作者、编辑核对，不作为角色台词朗读。基础页码、场景和原有知识依据[40页精简排版稿](40页精简排版稿.md)；台词在此基础上增加具体机制、对比与必要限定，并非逐字转述原有百科贴纸。

2026-11-12按用户反馈改为“从画面生发问题”：同时参考[当前扩图版](../扩图版/README.md)，每页另列“画面起点”，再写角色台词。知识正确并不代表适合放进该页；不凭空安排孩子询问图外的筑巢、幼鸟、蝙蝠或其他未被引出的题目。下列来源用于支持回答，不替代画面动机检查。

## 重点来源与适用边界

- **P4，戴胜羽冠：** [RSPB戴胜资料](https://www.rspb.org.uk/birds-and-wildlife/hoopoe/)支持兴奋时展开羽冠及嘴、翼识别特征。承接羽羽现身、羽冠展开的画面，不额外安排蝙蝠出场或让小满突然询问蝙蝠分类。
- **P6—P7，大杜鹃的声音：** [RSPB的Common Cuckoo资料](https://www.rspb.org.uk/birds-and-wildlife/cuckoo)与[Cornell鸟类声音交流资料](https://www.birds.cornell.edu/k12/bird-communication/)供核对鸟种及鸣叫的交流用途。P6从听见但未见鸟开始认识叫声；P7从枝头持续鸣叫解释同类交流、招引伴侣和领地信号。巢寄生虽是可讲的知识，但本页没有窝、蛋、幼鸟，也没有前文引出，已移出这一页台词。
- **P8，蜂鸟悬停：** [鸟类悬停运动研究综述](https://pubmed.ncbi.nlm.nih.gov/21098953/)讨论蜂鸟上、下拍产生升力及高功率需求。台词用翅膀翻转和托起身体解释，不给所有种通用的固定每秒拍翅次数，也不把“悬停”写成翅膀静止。
- **P9，猫头鹰静音飞行：** [翼羽结构综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC5206597/)及[安静飞行演化综述](https://academic.oup.com/iob/article/2/1/obaa001/5709817)讨论梳齿、柔软边缘、绒状表面等特征。用“许多”“帮助减小噪声”，不写绝对无声，不把每种羽毛结构的作用简化成唯一机制。
- **P10，企鹅：** [企鹅适应性资料](https://seaworld.org/animals/all-about/penguin/adaptations/)支持鳍状翅、羽间空气层等描述；[圣迭戈动物园的非洲企鹅资料](https://animals.sandiegozoo.org/animals/african-penguin)说明并非所有企鹅生活在雪地。不能把所有企鹅的气候和分布说成一样。
- **P11，鸵鸟：** [圣迭戈动物园鸵鸟资料](https://animals.sandiegozoo.org/animals/ostrich?qt-animals_page_content_tabs=0)说明强壮长腿、两趾及翅膀在奔跑转向时的平衡作用。不把两趾单独说成跑得快的唯一原因。
- **P13，鹦鹉脚与喙配合：** [圣迭戈动物园鹦鹉资料](https://animals.sandiegozoo.org/animals/parrot)及[厚嘴鹦鹉资料](https://animals.sandiegozoo.org/animals/thick-billed-parrot)支持对趾型脚、抓持食物与强喙的描述。问题从图中用脚拿果子出发，不把画里的软果实自行改说成硬坚果壳。
- **P14，家燕泥巢：** [Cornell家燕生活史](https://www.allaboutbirds.org/guide/Barn_Swallow/lifehistory)说明泥团、草茎与支撑位置。台词的干湿材料解释是通俗结构说明，不保证巢不会受雨水或损伤影响。
- **P15，军舰鸟喉囊：** [Cornell大军舰鸟资料](https://www.allaboutbirds.org/guide/Great_Frigatebird/id)支持雄鸟鼓起红喉囊进行求偶展示。新问法从右侧礁石上可见的鼓起红囊出发，不再让孩子先作“同一种红衣服”的抽象比较。[火烈鸟色素资料](https://animals.sandiegozoo.org/animals/flamingo)保留作编辑背景，不强行塞进本轮回答；收回书页属于故事魔法。
- **P17、P23—P24，鸣唱、呼叫与记录：** [Cornell鸟声学习指南](https://www.allaboutbirds.org/news/how-to-learn-bird-songs-and-calls/)及[Bird Academy声音行为资料](https://academy.allaboutbirds.org/avian-vocal-behavior-sound-visualizations/6/)支持叫声多样性与飞行鸣唱。[BTO百灵科介绍](https://www.bto.org/learn/about-birds/bird-families/alaudidae-larks)说明飞行鸣唱的领地展示作用。个人图形记录须有图例，不能把长短直接等同于一种固定意思。
- **P18，录音操作：** 本页是小满按桌上录音键，故从按钮、麦克风和录音过程发问，回答采用“振动—电信号—记录—播放”的基础声学流程。没有先安排她在野外播放录音。[Audubon回放规范](https://www.audubon.org/magazine/how-use-birdcall-apps)仍是背景观察原则，不作为这页已发生的情节。
- **P19，湿地中的觅食方式：** 从黑水鸡游动、白鹭和苍鹭站在浅水中的可见对比，承接原稿的湿地觅食知识。游动的黑水鸡脚被水遮住，不让小满先说它的脚不像鸭蹼；也不因白鹭、苍鹭站着，就说它们不能游泳。
- **P28，伯劳与绣眼鸟：** [Cornell伯劳生活史](https://www.allaboutbirds.org/guide/Loggerhead_Shrike/lifehistory)及[美国鱼类与野生动物管理局的伯劳介绍](https://www.fws.gov/story/loggerhead-shrikes-tales-larder)支持借尖刺固定、储存食物；所引美洲种用于说明伯劳中常见的行为，不据此宣称每一种伯劳行为完全相同。[BirdLife Australia绣眼鸟资料](https://birdlife.org.au/bird-profiles/silvereye/)说明植物细材与蛛丝编巢，不把所有绣眼鸟的材料清单说成完全一致。
- **P29，鹈鹕和绿头鸭：** [圣迭戈动物园鹈鹕资料](https://animals.sandiegozoo.org/animals/pelican)明确喉囊用于捕获和排水，不是长期储存食物；[Cornell绿头鸭资料](https://www.allaboutbirds.org/guide/Mallard/id)支持在浅水中前倾觅食。不能把所有鹈鹕都写成从空中俯冲，也不能把所有鸭都写成只会倒立、不潜水。
- **P31，电线：** [MIT工程学院解释](https://engineering.mit.edu/ask-an-engineer/how-do-birds-sit-on-high-voltage-power-lines-without-getting-electrocuted)与[USGS鸟类触电资料](https://www.usgs.gov/publications/electrocution)支持电位差及跨接不同电位造成危险的解释。两脚在同一导线附近通常电压差很小，不写成“鸟爪绝缘”“鸟天生不怕电”或“任何时候都没有电流”。
- **P32，模仿人声：** [Cornell模仿声音的鸟类介绍](https://www.allaboutbirds.org/news/which-birds-are-the-best-mimics/)及[Audubon鹦鹉模仿人声的解释](https://www.audubon.org/magazine/why-do-parrots-talk)支持鹦鹉、椋鸟类及部分鸦科鸟的模仿能力；[鹦鹉模仿声调查研究](https://www.nature.com/articles/s41598-022-24335-x)支持种间及个体差异。不得用“只会学、不懂意思”否定所有鸟的认知能力，也不能因能模仿就声称它懂得每句话。
- **P33，家鸡驯化：** [863个基因组的研究](https://www.nature.com/articles/s41422-020-0349-y)说明家鸡与原鸡的祖源关系及后续基因交流。使用“主要野生祖先”，不宣称只涉及一种、一次简单变化；不把野化家鸡等同于野生原鸡。
- **P34，鸣管：** [Cornell鸣管教学资料](https://academy.allaboutbirds.org/built-to-sing-the-syrinx-of-the-northern-cardinal/)与[鸣禽呼吸发声系统综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC4532670/)说明气流、振动组织和肌肉控制。不同鸟的结构不同，不把某种鸣禽的双声部能力说成所有鸟共有，也不编造本页鹪鹩的固定分贝数。
- **P35，藏橡果与种子传播：** [鸦科藏种与植物更新综述](https://academic.oup.com/condor/article/118/2/215/5153253)支持贮藏行为可促成种子传播。未取回不一定全是忘记，种子也不是每颗都能发芽，更不能说松鸦有意替人类种树。
- **P36，录音里的声音用途：** 从小满闭眼播放旅途录音，自然问鸟叫在传递什么消息，依据[Cornell鸟类声音交流资料](https://www.birds.cornell.edu/k12/bird-communication/)说明求偶、领地、联络和报警等用途。没有把录音预设为报警声，也不在没有危险场景的情况下突然引入跨物种报警实验。

## 文稿层面的约束

1. 每页只保留小满一次发言、羽羽一次回应；可以围绕同一画面的两种鸟作具体对比，但不堆砌无关知识。小满不必每次都提问，也可以惊呼、说出发现、猜测或试探。
2. 对话必须有当页或明确前文中的观察起因。知识可以在羽羽的回应中自然延伸，如P32由听八哥、鹩哥引到其他模仿人声的鸟；不能为了讲某个知识点，先让小满凭空问它。图外延伸不自动授权改画面。
3. 小满用孩子自然说话的句式，羽羽承接她的发现或疑问。语气词随情境使用，不机械重复“啦？呀？”，也不靠轮换句末助词制造变化。不使用空泛导语，不替小满先安排专业结论、无根据的误解或与现场无关的假设；不要每页都写成“先假设一个错误，再让羽羽纠错”。
4. 台词草稿不自动覆盖原有图内文字；若用于贴纸排版，需要另行按可读字号和留白精简。
