# 第二章：寻找最美鸟鸣

本章为P17—P24，共8页，包含1页章扉、6页探索与出发内容、1页回馆整理。目录内PNG均为最新的场景与服饰多元化版本；P19于2026-11-11完成双手局部优化，随后P20、P23也完成手部专项修订，其余图页保持不变。

## 当前版规则

- 画幅统一为1:1，延续儿童卡通水彩与彩铅风格；温暖的阅读感通过不同场景的光线与配色呈现，不统一套用金色夕阳。
- 小满亲历真实连续的环境，走、听、录音、寻找和整理；不采用巨书里的场景拼贴或鸟类陈列式构图。
- 根据鸟类栖息地丰富场景，不强行切换季节。衣服、鞋帽与地面干湿、气温、日照和活动相适应。
- 采用精简正文，通常2—3行；鸟类知识单独放在角落的“鸟类小百科”贴纸中。
- 图内普通标题仅保留文字，字号比正文略大；不展示页码或分隔符。章扉保留“第二章”。文件名继续使用`P页码｜标题.png`便于排序。
- 保持小满5岁、短发与人物面貌一致；羽羽始终为戴胜鸟，不与玄凤鹦鹉等鸟类混淆。

## 内容连续性

从带录音机出发，到湿地、森林、山谷、夜间与清晨听鸟鸣，最后回到图书馆把声音画下来。

P19区分白鹭、苍鹭与红额黄嘴尖的黑水鸡；P21区分兀鹫盘旋和游隼俯冲；P22保留夜鹰与朴素棕褐色夜莺；P23让画眉、百灵、黄鹂分布在适合的环境层次中。

P24笔记本保留已确认的三行内容：布谷鸟配金色双音符与紫色长线，小鸟配蓝色小点，棕色小鸟配珊瑚色弧线。录音机波形与手绘记录符号分开呈现。

## 2026-11-11：P19双手优化

- 仅调整小满拿录音机与扶栏杆的双手及必要腕部连接，保持湿地栈道、行进观察动作、脸型表情、服饰鞋帽、鸟类、画面构图及现有文字。
- 拿录音机的手采用四指沿机身侧下缘自然弯曲承托、独立拇指轻扶另一侧的握持关系；屏幕、红键和双麦克风保持清楚，避免手指与机身融合。
- 扶栏手的掌根贴合木栏顶面，四指顺着栏杆轻弯，拇指位于掌侧近缘；不画四指卡通手，不强行摊开五指，手腕自然连接袖口。
- 按[绘本插画Skill](../../../skills/childrens-picturebook-illustration/SKILL.md)分别放大检查双手，区分自然遮挡与缺指。正文与百科不改写，标题仍无页码。
