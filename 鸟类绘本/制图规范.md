# 《羽毛图书馆：会飞的鸟类大百科》制图规范

整理日期：2026-11-10。本文件是当前[插画Skill](../skills/childrens-picturebook-illustration/SKILL.md)的中文执行说明，不是新增的绘本脚本，也不表示所有历史图片均已按此重绘。

制作时结合[40页精简排版稿](文本/40页精简排版稿.md)、[精简正文](文本/40页精简正文.md)及对应章节README。用户最新确认的逐页修改优先于旧稿、旧提示词和参考图；出现冲突应先核对，不擅自恢复旧设定。后续通用规则变化需同步更新Skill与本规范。

## 1. 画幅与整体风格

- 面向4—8岁亲子共读，全部使用1:1方形画幅，包括封面、封底与章扉。旧稿的“横版”不再作为默认要求。
- 儿童读物卡通风格，圆润、表情清楚，采用水彩和彩铅质感；不转为写实照片或冷峻画风。
- 整体温暖、柔和、有纸张质感。可用米白、蜂蜜黄、珊瑚色、陶土色与柔和绿蓝，但温暖不等于每页都用金色夕阳。
- 按生境与时间区分晨雾、日光、林荫、月色、秋光和室内灯光；画风保持一致，光线不必一致。
- 不添加水印、品牌标识、乱码或稿件未要求的装饰文字。

## 2. 固定角色与鸟种辨识

### 小满

- 5岁女孩，短发；脸型、年龄感、发型与人物面貌连续，不因换装变成另一个孩子。
- 随身小布包，露出笔记本和彩铅。第二章起按情节使用便携录音机，避免无意复制出多台相同道具。
- 衣服、鞋帽随天气、地面与活动变化。黄色雨靴不是永久标识；无雨水、泥地时不默认穿雨靴。
- 观察时眼神明确望向鸟；画画时看记录，听录音时可闭眼微笑，动作应与情节相符。

### 羽羽：戴胜鸟书精灵

- 金棕色身体；细长、略向下弯的鸟喙。
- 肉桂色扇形羽冠，羽端有明确黑色；羽冠随情绪张开或放松。
- 黑色与米白相间的横斑翅膀，尾羽像书签。
- 不能画成玄凤鹦鹉：禁止橙色脸颊、短钩状鹦鹉喙、纯黄色光滑头冠。

### 布谷鸟：独立的声音线索

- 与羽羽是不同角色。光滑无冠的灰色头胸、灰褐色翅膀、浅色腹部细横斑、黄色眼圈、细直喙、带浅色斑点的长深色尾羽。
- 可卡通化，但不能借用戴胜的羽冠、金棕色身体，也不能画成啄木鸟。
- 显形鸣叫时，两脚抓住树枝，身体侧向近水平，抬头张嘴；不竖直抱住树干。
- 非主角页面可只用远处剪影、声波或两枚小金色音符暗示，不频繁画实体、不抢主体。
- 金色双音符保留为布谷鸟线索，其他鸟声可用轻巧蓝色、珊瑚色声波区分。
- Skill提及的用户布谷鸟参考照片未作为本次上传附件提供；跨环境复用时应另行提供照片，不假定模型能访问原聊天附件。

其他鸟类也须核对关键形态、大小、习性与生境，不用通用小鸟外形替代所有鸟种。知识表述避免绝对化，不能把“有模仿能力”画成“每只都会说人话”。

## 3. 叙事、构图与场景多样性

- 小满真正走入鸟类环境，通过走、停、侧耳听、扶栏、寻找、记录等动作探索；不固定为画面边角的第三方旁观者。
- 默认儿童视角的中景，兼顾表情与栖息地。避免极端拉远使小满变成小点，也避免把鸟放大成展示标本。
- 用前景枝叶、中景行动、远景生境及路径、水流、枝条建立自然透视。鸟可以停在远处较高的树枝上，不靠无限拉远镜头表达高度。
- 相邻页改变人物位置、动作、朝向、镜头、光线与空间层次，避免同一蹲姿、同一条栈道、同一片金色芦苇反复出现。
- 优先根据鸟类活动选择森林、灌丛、草原、田边、湿地、溪流、湖岸、城市与室内，不为凑变化强行切换四季或把鸟搬进不适合的环境。
- 正文探索页使用真实连续环境，不默认巨书托景、分框拼贴、鸟类排队陈列。封面及明确的魔法转场可按脚本使用书本元素。
- 图书馆整理页表现实际桌面、书架、手账与活动，回忆鸟类可画在记录里，不默认实体鸟群围桌。

## 4. 服饰与鞋帽适配

| 环境 | 服饰与鞋帽原则 |
| --- | --- |
| 干燥草地、晴天郊游 | 轻便上衣、合适长短裤、帆布鞋或运动鞋；需要时戴遮阳帽 |
| 干燥田边、石路 | 合适长袖或马甲、长裤、稳固步行鞋或徒步鞋 |
| 浓密、带刺灌丛和林下 | 长袖长裤、包脚步行鞋，不裸腿钻刺丛 |
| 溪流、浅水、湿地泥地 | 防水雨靴及适当衣物；干燥栈道不一概强制雨靴 |
| 开阔湖岸、日晒干地 | 轻便衣服、运动鞋或徒步鞋、遮阳帽；按站立地面判断防水需求 |
| 清冷大风山脊 | 防风外套、长裤、稳固鞋；按温度配帽 |
| 寒冷、雪地或极地 | 保暖外套、帽子、围巾与适合的保暖防水鞋靴 |
| 室内整理、画画 | 舒适衣裤、开衫、室内便鞋；帽子外套收好 |

逐页同时检查植被、地面干湿、气温、光线、衣物厚度和鞋底用途。服装颜色可变化，不能永久固定黄色外套与黄色雨靴。

## 5. 绘本文字与版式

| 元素 | 规则 |
| --- | --- |
| 普通内页标题 | 只保留标题文字，不显示`P19`、`19｜`等页码；字高约为正文的115%，比正文大一点，不小于正文，也不占满顶部 |
| 章扉标题 | 保留“第几章＋章名”，独立层级，可适当放大 |
| 封面标题 | 使用主书名层级，不套用普通页字号 |
| 绘本文字 | 通常每页约20—40个汉字、2—3行，一个主要动作或情绪；按当前确认稿逐字提供 |
| 百科贴士 | 角落的米白手账贴纸，标题为“鸟类小百科”，知识与故事分区，不遮人物、鸟或关键道具 |
| 默认文字颜色 | 标题柔和古金色，正文清晰暖深棕色，注意行距与页边距 |

- 先安排主要行动，再利用安静天空、墙面等低细节区排字，必要时加轻薄米白底，不为文字牺牲主画面。
- 成品带字图必须包含指定标题、精简正文和该页要求的贴士；只有用户要求无字底图时才留白。
- 封面、献词、互动页与封底按各自角色排版，不强行每页都加百科贴纸。
- 图内标题无页码不等于文件无页码，文件名仍保留P页码。
- 逐字检查漏字、错字、重字、标点与段落；正文、知识和实际画面必须一致，不能删了某种鸟却保留其旁白。

## 6. 重点连续性与人体比例

- P24笔记本沿用确认的三行：灰色布谷鸟配金色双音符和紫色长线，小鸟配蓝色点，棕色小鸟配珊瑚色弧线；录音机真实波形与儿童手绘符号分开表达。
- 桌椅、笔记本、录音机与儿童身体保持合理比例，手指、四肢、关节和握持关系自然。
- 坐姿不扭曲、不挤压腿部；使用适合儿童的椅子，双腿自然向前、膝盖弯曲，必要时双脚落在脚踏上。P30已确认的修正姿态应保留。
- 远距离观察，不抓鸟、不翻挖食物缓存；避免血腥捕食特写，行动地点应安全。

## 7. 封面专属要求

- 1:1方形。中央旧绿皮《鸟类大百科》书脊朝左、封面半开，书页像展开的翅膀。
- 小满站在书脊上，一手扶页边、一手伸向羽毛。羽羽从书缝飞出，书签尾羽拖出细小羽毛路径，回头看声音线索。
- 淡金晨光，远处麻雀、猫头鹰、企鹅、丹顶鹤、鹦鹉剪影保持次要。
- 右下角极小布谷鸟剪影与金色双音符，不能抢主体。
- 主书名：《羽毛图书馆：会飞的鸟类大百科》。封面正文为“翻开一页，就飞进一个鸟的世界。”“听，布谷鸟在叫。”
- 羽毛书签提示：“羽毛和金色音符藏在哪里？跟着它们，开始探险吧。”
- 封面衣着按已确认参考图延续，不将其服装固定套到所有内页。

## 8. 制作与修订流程

1. 核对页码、页角色、最新正文、贴士和用户确认过的修改；读取Skill及相关章节README。
2. 为本章列出“生境／动作／镜头／衣服／鞋帽／光线”简表，排除相邻页同质化。
3. 选择当前已确认图作为画风和人物参考，明确只参考哪些元素，不继承旧图中的错误或不合场景的服饰。
4. 提示词按“画幅与页角色→故事动作→人物→场景→构图与留白→画风→逐字文字→保留项与禁止项”组织。
5. 生成后检查画幅、角色、鸟种、姿态、视线、场景服饰和文字，局部不合格优先做针对性修订。
6. 修订前区分固定项与可改项，说明“保留哪些，只改变哪些”，避免改一个道具却改变人物、构图或全文。
7. 替换正式图前保留旧版；按正式文件名归档，更新章节索引和必要的画面建议。

## 9. 文件、版本与Git范围

- 命名：`P页码｜标题.png`，如`P19｜湿地里的三位邻居.png`。不补零，不用旧16页编号冒充新40页页码；按页码数值排序。
- [四章正式目录](40页版图片/README.md)：第一章P3—P16，第二章P17—P24，第三章P25—P30，第四章P31—P36。P1—P2是开篇，P37—P40是结尾部分。
- 各章目录只收录当前正式图与README；不要把备份当正式页、重复来源图当新增页。
- 旧版放在“历史版本”，原始生成图不删除；备份和原始生成图暂不上传Git。
- Git同步只在用户明确要求时进行，使用明确文件范围暂存，不通过`git add .`混入备份、无关修改或尚未确认的页面。
- 当前规范不代表印刷出血、成品尺寸、DPI或色彩配置已确定；正式印刷前另行确认，并再次校对文字和图像质量。

## 10. 交付验收清单

超清版沿用当前正式图对应的v1文案，P1—P36取最新扩图版，P40取现有封底；不因提升分辨率自动套用v2重排稿，也不把尚无图的P37—P39计作已完成。成果独立存于`超清版/`，每页提供3000px PNG、嵌入字体PDF、可编辑SVG及两级无字底图。实际文字四边余量至少12%，原图与原文稿保留。P40文案与原短稿的差别记入超清版校对文字。
