# 鸟类绘本 · Qwen2.1 重制版（2508px 场景）

**这是重绘，不是超分。** 每页场景由 Qwen-Image-2.1-Turbo 依据同一页的 1254px 无字源图重新生成，
构图、角色、配色尽量贴近原作，但像素全部重新生成，细节不保证与原作逐像素一致。

## 处理链

1. `正式素材/<章>/<页>/无字图-1254px.png` 作为唯一参考
2. Qwen-Image-2.1-Turbo，8 步 sigma 表，cfg 1.0，seed 424242，resolution 2496
3. 逐通道均值/标准差匹配回该页 1254 源图（在 Qwen 出图的像素网格上统计），抵消模型整体的压暗与降饱和
4. 缩放到 2508×2508，写 300 PPI

## 目录

- `<章>/<页>/01-原图-2508px.png`：该页 2508×2508 无字场景
- `清单.json`：逐页 SHA-256、尺寸、锐度对比与生成参数

文字层（标题正文、鸟类小百科）不在本目录内，仍是 `正式素材/` 里的独立透明 PNG。

## 需要注意的一致性

重绘可能改变细节。已确认需要保持的硬约束：P24 录音机造型与手部比例、P18 听音姿势、
每页物种与章节页码对应。详见[正式素材索引](../正式素材/README.md)。
