# PNG分层版续制

全书授权范围为40页。目前P1—P30齐全；P32另有新版无字图。P31—P40保留旧完整PNG，待任务完成后再替换。**最新规则：后续超分由用户本地完成，Agent不再执行CPU/GPU超分或场景插值放大。新场景只保存生成原尺寸（当前一般为1254×1254）；已有2508px及文字PNG保持原样。**

`PNG分层版待续制任务.json`包含19项未完成的图像生成请求。参考路径相对于仓库根目录，使用时解析成实际本地路径。第一张文字样式参考已经改为仓库内的P16确认稿，不依赖未上传的本地试样。按原请求的`transparent_background`生成，不能为避开额度而改用电脑字体、涂抹场景或冒充已完成。

生成结果按行写入JSONL，每项包含`id`、`page`、`kind`（scene或sheet）、`path`（实际生成PNG）。页面文案与裁切角色见`PNG分层版页面清单.json`。

使用`制作PNG分层版.py`导出：

```bash
python 热带雨林绘本/制作记录/制作PNG分层版.py \
  --pages 热带雨林绘本/制作记录/PNG分层版页面清单.json \
  --results /实际续制工作目录/results.jsonl \
  --output 热带雨林绘本/超清版 \
  --expected 19
```

导出脚本不再依赖CUnet、CPU二进制或模型。场景直接复制为`插画原图-1254px.png`，核对源文件和归档文件SHA-256完全相同；若实际输出为其他方形尺寸，按真实像素命名，保持文件原样。不会新建2508px或3000px场景。文字素材继续按确认方式合画、裁切，图像内容编辑仍使用图像生成工具。

[根目录CUnet工具](../../CUnet/README.md)保留供用户自己电脑手动运行；建议本地输出写入Git忽略的`CUnet/output/`，不自动上传这些新增超分文件。

剩余页逐页核对原尺寸PNG字形、手部和完整背景。P37保留填写线、勾选框和空白画图区；P38不印版权占位符；P39纸签为亲子延伸，P40为回想提示。原尺寸场景与文字素材验收齐全即满足后续交付要求，不以超分文件为完成条件。届时仅移除被替代的旧整页和旧参考，保留新的无字原图，并更新文件清单、预览、根索引、完成状态与Git。
