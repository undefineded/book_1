# 热带雨林大冒险 · 2508px 重制版

40 页全部是 Qwen-Image-2.1-Turbo 的重绘结果，**2508×2508，300 PPI**。

**这是重绘，不是超分。** 每页以同一页的 1254px 源图作参考重新生成，构图、角色、配色尽量贴近原作，
但像素全部重新生成，细节不保证与原作逐像素一致。

## 处理链

1. 1254×1254 源图 作为唯一参考
2. Qwen-Image-2.1-Turbo，8 步 sigma 表，cfg 1.0，seed 424242，resolution 2496
3. 逐通道均值/标准差匹配回该页旧的 CUnet 2508，抵消模型整体的压暗与降饱和
4. 缩放到 2508×2508，写 300 PPI
