# 图片生产与验收规范

本文件属于`childrens-picturebook-illustration` Skill。通用的保真、版本和验收规则适用于相关绘本；具体尺寸与交付形式以各项目最新确认要求为准。下列分层PNG规格对应当前已授权的《热带雨林大冒险》，不据此改动其他绘本。

**最新指示：后续超分由用户本地完成。Agent不再执行CPU/GPU超分，不为场景额外插值放大；直接交付生成原尺寸。既有超分文件与工具保留，不自动删除、重做或迁移。**

## 1. 生成前固定输入

- 对照最新MD、页面清单、人物规范和本页确认修订，明确页面角色、逐字文案、场景、服装、鞋、动作、动物数量及道具。
- 查看实际参考图。已经确认的页面与样式直接复用；局部修订锁定其余构图与身份，不重新设计整页。
- 雨林文字样式参考为仓库中的[P16确认合画](../../../热带雨林绘本/超清版/P16｜远处是谁在打鼓/00-标题与百科合画-透明底.png)。它提供笔触与纸签样式，其他页必须使用自己的文案。
- 运行前核对原始输入尺寸、输出目录和可用空间。像素尺寸、PPI和实际打印尺寸分开记录；不能把设置300 PPI描述为增加细节。

## 2. 无字场景与源图留存

- 无字场景与文字素材分别制作。移除标题正文、悬浮纸签、装饰边框、排字白斑和旧文字区；用图像编辑工具补回连续、真实的环境。
- 不能留下涂抹、模糊块、纸签轮廓或故意留出的排字空区。真实天空、墙面、书页，以及P37实体笔记纸和功能性画图区按实际物体与用途保留。
- 保留已确认的人脸、年龄、服装、站坐姿、手部接触、动物数量、物种和羽羽标志。去字和超分都不构成重新设计这些内容的授权。
- 确认的1254×1254无字源图归档到各页`插画原图-1254px.png`，进入本轮已授权上传的Git交付；同时保留原始生成文件。不能只把临时环境路径当作源图保存。
- 保存实际生成尺寸与来源。输入不是1254px时先核实原因，不先插值成1254px再冒充原生输入，也不从3000px成品缩小后冒充源图。

## 3. 超分仅由用户本地执行

- Agent只保存生成原尺寸的无字场景，当前为`插画原图-1254px.png`；遇到其他实际尺寸时按真实尺寸命名，不缩放来凑规格。文件直接复制并核对SHA-256，不再调用超分二进制。
- 根目录[CUnet工具](../../../CUnet/README.md)和[模型清单](../../../CUnet/models.json)保留供用户自己电脑使用。此前1254→2508的生产流程已退出云端默认路径，不能因旧脚本或旧复核记录自动重跑。
- 用户本地可选择两倍超分及最终排版尺寸；建议把新增本地结果写入已忽略的`CUnet/output/`，不自动提交到Git。已提交的存量2508px文件保持原样，本规则不授权删除它们。
- 后续整理工具代码时可以做静态检查；不把实际CPU/GPU推理当作默认验证步骤。用户新的明确指示优先。
- 原生生成像素、AI重建像素、常规插值像素必须准确区分。不能称AI超分结果为原生高分辨率重绘，不能只用“超清”省略实际处理链路。
- 用户本地的CUnet工具只处理RGB场景，透明标题、正文与百科PNG独立保留。场景重画和文字重画仍使用图像生成工具。

## 4. 文字合画、透明背景与修字

- 标题正文与右侧纸签在一张透明图中合画，两块互不接触，之间留全高透明裁切带；保留原尺寸合画，再裁出独立素材。确认的P15分离试样可以直接复用。
- 文字直接绘入PNG，保留确认的手写笔锋、字重、配色和行距。标题正文带米白暖奶油渐变阅读底，外围渐隐透明；百科保留纸张、标题条、叶饰及边框，纸签外透明。
- 棋盘格仅用于预览透明度，不能烘焙进成品。裁切不得切字、切边框或丢叶饰；保留透明外边距，检查两块没有被渐变或杂点粘在一起。
- 内容按最新MD逐字渲染，不打印文件页码、制作指令或未确认版权信息。封面、扉页和献辞不硬加百科；P37为可填写观察记录，P39为亲子延伸，P40为回想提示。
- 放大检查最终PNG的字形、标点、漏字、重字及断行。源字符串正确、OCR正确都不能替代实际笔画检查。
- 错字在用户指定图上局部修改，保留其余笔锋、字号、布局与背景；不能为修一个字更换宋体、电脑字体或重排整行。可记录修补区域，并验证区域外像素保持不变。
- 特别保留P16正文`呜——呜——`的无眼点“乌”部，同时保留百科`共鸣`的“鸣”。P4确认的“咦”局部修订也不能退回旧稿。
- 仅调整场景分辨率时，文字与合画PNG原样复用，用文件SHA-256确认没有改变；不随场景尺寸自动缩放这些独立素材。

## 6. 逐页验收与断点交接

- 查看完整场景，再分别放大双手，检查四指加拇指的结构、合理遮挡、手腕肘肩连接、扶栏与持物接触、重心和坐姿支撑；不强迫每个角度都露出五个指尖。
- 核对角色身份、服装鞋帽、动物种类与数量、羽羽的戴胜特征和挂件、水面倒影、旧纸签区域的环境及页面文案。只核对缩略图不算完成手部或文字验收。
- 检查原始PNG实际尺寸与元数据、RGB/RGBA模式、透明边缘、裁切完整性、文件可读取性和文档链接。新场景逐字节保留原文件，不为了设置300 PPI改写它；既有文字素材按确认的导出规格保存。只记录实际完成的目视或程序检查。
- 更换文件名、生产方式或分辨率后，同步每页README、预览、总索引、文件清单与SHA-256、制作记录、Skill和交接文档，避免文档继续链接旧3000px或已移走的代码。
- 完成状态依据真实文件与验收结果分别记录：场景完成、文字完成、待修订、待生成。保留旧页作备份时明确标注，不能把旧页或占位图计作新版完成。
- 接口提示`usage_limit_reached`时停止提交新的生成请求，保存已完成结果和逐项待办。恢复时间按接口提示写清绝对日期、时区及不确定性，不推断每日固定额度；可继续进行已授权的文件整理与原尺寸归档，不因此运行超分。
- 交接保留仓库内参考图、逐字文案、可复用提示词、实际输入输出、源图路径与续制步骤；易失的`/tmp`路径只作当前环境补充，不作为唯一依赖。
- 替换前核实旧版可从历史副本或Git提交恢复，再移除被替代的导出成品。原始图、确认源图和阅读版保留；编译产物、模型缓存与下载包按可重建依赖管理。
- 仅在用户明确要求时重置Git历史。保留当前完整文件快照，验证可用后再清理旧对象，同时更新依赖旧提交恢复的说明；历史重置后不再承诺从旧提交找回已删除成品。
- 已有上传授权时，完成验收后将素材、状态与规范一起同步Git并核实远端；没有上传授权时保存本地。发布状态以实际Git提交为准，不把“已生成”“已暂存”说成“已上传”。
