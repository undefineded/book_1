# 排查与工具

做小百科卡片要用到的东西，一共三样：一个排版工具、一个字体对比页、一份生僻字排查报告。

```
排查与工具/
├─ 纸签编辑器.html          排版工具（双击打开，无需安装、无需联网）
├─ 字体对比.html            两款手写体的同句对比 + 生僻字逐字检查
├─ 字体/
│   ├─ 冰莓粉可爱小狗手写体.ttf
│   └─ mini圆体.ttf
└─ 生僻字排查.md            两本书 80 页的生僻字扫描结果
```

## 纸签编辑器.html

米白纸卡 + 橙色虚线 + 金色标题条的纸签排版工具，输出透明 PNG。

- **章节文字**：可导入 `.md` / `.txt` / `.json`。仓库根目录的 `小百科.json` 直接拖进去就能按书和页码筛选
- **本地字体**：ttf / otf / woff / woff2 都能导入，字体会随 PNG 一起导出，不用装进系统
- **默认颜色**：正文 `#230701`，标题 `#502B03`（第一个文字层自动用标题色）
- 导出：选 2× 高清，输出 `2020×2020` 左右的透明 PNG

## 字体对比.html

同一句小百科文案在**冰莓粉可爱小狗手写体**和 **mini圆体**下的效果，外加 17 个生僻字逐字检查（红框 = 该字体没这个字）。

两款都缺 `䴙 䴘 䴓` 三个字，其余 14 个都有。替代写法 **鸊鷉 / 鳾** 两款都能正常写。

## 生僻字排查.md

按章节列出两本书（鸟类绘本 40 页 + 热带雨林绘本 40 页）的扫描结果。结论：**现有文案里没有一个生僻字**，
真正的风险只在新增鸟种时。文档里附了「生僻字鸟种该放进哪一章」和「鸟名用字安全表」。

## 一点说明

`字体/` 里两个 ttf 是从字体合集里挑出来的第三方字库，仅作本项目排版用。
如果要公开发布或商用，请先确认这两款字体的授权范围。
